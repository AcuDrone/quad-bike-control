## 1. Pure law
- [ ] 1.1 `include/SteerParkLaw.h` (header-only, no Arduino / Constants.h): `SteerParkRung { uint8_t duty; uint16_t ms; }`; `SteerParkParams { int32_t triggerTol; int32_t doneTol; int32_t moveMin; uint32_t settleMs; uint32_t gapMs; uint8_t maxPulses; SteerParkRung rung[3]; }`; `SteerParkState` (phase ARMED / WAIT / DONE / GAVE_UP, rung index, pulse count, pulse start ms, pulse ms, position before the pulse, pulse direction, last duty / ms, `reset()`); `SteerParkResult { action NONE|PULSE|DONE|GIVE_UP; duty; ms; dir; moved; note NONE|SAME|ESCALATE|OVERSHOOT|WRONG_WAY }`; `steerParkLadderValid(params)` (each rung within bounds is the caller's; non-decreasing duty and ms).
- [ ] 1.2 `steerParkStep(state, params, now, err, pos, settledMs)` (0.1° ints): `settledMs < settleMs` → reset, NONE. ARMED: `|err| > max(triggerTol, doneTol)` → PULSE rung 1 toward `sign(err)`, count 1, record start / pos / dir. WAIT: until `now − start ≥ ms + gapMs` → NONE; then evaluate in order: `|err| ≤ doneTol` → DONE; sign flipped and `|err| > doneTol` → OVERSHOOT, rung 1; `moved ≤ −moveMin` → WRONG_WAY, rung 1; `moved ≥ moveMin` → SAME; else ESCALATE (cap rung 3); then `count ≥ maxPulses` → GIVE_UP, else PULSE toward `sign(err)`. DONE / GAVE_UP: NONE until reset (budget per parking: DONE does not refill it — from DONE, a later `|err| > trigger` resumes with the remaining budget at rung 1).
